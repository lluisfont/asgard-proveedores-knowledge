# Guia del modelo de datos

La fuente actual es [modelo de datos de master](../general/data-model.md) y [referencias SQL candidatas](../general/table-reference.md). El esquema fisico de master no esta versionado en el repositorio auditado.

El antiguo diccionario de 1,055 tablas y 10,111 columnas procede del dump historico de Peru y se conserva como tal en `source-audits/brownfield/reports/data_dictionary/`. Sus tipos, claves, relaciones y procedimientos no se trasladan a master por suposicion.
