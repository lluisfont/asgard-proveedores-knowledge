# Instalacion

## Instalar En Checkout De Programador

Desde este repo de Knowledge:

```powershell
.\install-knowledge-pack.ps1 -TargetRepo "C:\ruta\al\checkout"
```

Dentro del checkout:

```powershell
.\scripts\knowledge\update.ps1
```

## Uso Sin Codigo

Usar directamente `knowledge/`, `source-audits/` y los crosswalks.
