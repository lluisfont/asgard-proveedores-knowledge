## VAR-001 — Tipos y población del contador de inventario

**Ámbito: Perú/P; AS-IS y RISK del consumidor.** El contador nacional usa `parseInt(vehiculo.pendiente) !== 1` sobre todos los vehículos recibidos. El botón y el filtro «Pendiente» exigen, en cambio, `vehiculo.pendiente === 1`. No se normaliza ese campo antes de tomar las decisiones. La siguiente tabla compara una fila recibida, sin atribuir esos valores a una respuesta real del backend:

| Valor de `pendiente` | Filtro «Pendiente» | Aporta a «Completados» |
| --- | --- | --- |
| número `1` | Sí | No |
| cadena `"1"` | No | No |
| número `0` o cadena `"0"` | No | Sí |
| `null` o campo ausente | No | Sí |
| booleano `true` o número `2` | No | Sí |

Por tanto, «Completados» no verifica por sí solo una inspección realizada: un campo ausente también incrementa el contador. La cadena `"1"` queda fuera del filtro aunque tampoco sume como completada. **RISK:** contrato de tipos inconsistente entre filtro/botón y agregado; definir y normalizar el dominio es una decisión pendiente, no una corrección ya aplicada a la aplicación.

El badge muestra el conjunto recibido, no el subconjunto visible tras los filtros de columnas: una fila visible de dos puede conservar «Completados 1 de 2». Solo se emite este contador con `embarqueTipo === 'nacional'`; el inventario local no lo emite. No se demuestra que la API produzca valores nulos, cadenas o booleanos, ni se valida su persistencia.

Evidencia fijada: [P condiciones del botón, L75-L87](https://github.com/KPO-Group/proveedores/blob/95fe9a4c3b3cddd84be922cc0e1eb9c88603df62/index_archivos/embarques/componentes/inventario-local/tabla-vehiculos.js#L75-L87), [P conteo y filtro, L162-L207](https://github.com/KPO-Group/proveedores/blob/95fe9a4c3b3cddd84be922cc0e1eb9c88603df62/index_archivos/embarques/componentes/inventario-local/tabla-vehiculos.js#L162-L207), [P badge y evento, L8-L16](https://github.com/KPO-Group/proveedores/blob/95fe9a4c3b3cddd84be922cc0e1eb9c88603df62/index_archivos/embarques/componentes/inventario-local/index.js#L8-L16), [P recepción del evento, L147-L149](https://github.com/KPO-Group/proveedores/blob/95fe9a4c3b3cddd84be922cc0e1eb9c88603df62/index_archivos/embarques/componentes/inventario-local/index.js#L147-L149).
